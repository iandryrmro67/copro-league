# Ton des textes de Copro League

Validé par l’utilisateur le 7 octobre 2026 pour l’ensemble de l’interface, administration comprise.

Public : un groupe de potes, sans private jokes. Ton sportif, sérieux et direct, avec quelques touches d’humour internet Gen Z français et américain. Tutoiement dans les consignes. Conserver le vocabulaire de la ligue : MVP, draft, awards, rating, ELO, facts, PlayStyles et graille.

Les titres annoncent la page ou la fonction. Les boutons décrivent l’action. Les erreurs expliquent ce qui bloque et comment reprendre. L’humour est ponctuel, principalement dans les Banter Awards, les Allegations et quelques états vides. Les seuils, formules, restrictions et risques de perte ou remplacement de données restent explicites.

Exemples : « Les matchs », « Les joueurs », « Les stats », « Les saisons », « Compose les équipes », « Les facts du moment », « Le terrain tranche ». INTERSTELLAR : « Beaucoup de tirs hors cadre. La NASA suit le dossier. » NO TOUCHES JUST VIBES : « Peu de touches de balle. Les vibes, elles, ne se comptent pas. »

La réécriture conserve le barème V2 actuellement publié et la limite de stockage vidéo de 50 Mo. Les textes de l’ancien checkout Sites ne doivent pas servir de référence aux fonctions actuelles. Les descriptions des awards figés utilisent les textes actuels à l’affichage ; les gagnants, scores, règles, snapshots et données enregistrées sont conservés.

Vérification locale : 197 tests réussis, TypeScript et compilation Next réussis. Les assertions existantes qui dépendaient d’un ancien intitulé ont été mises à jour. Aucune migration de données.
