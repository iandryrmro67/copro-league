# Copro League Implementation Plan

**Goal:** Construire et vérifier les parcours de gestion football à 5 décrits dans docs/brief.txt.
**Architecture:** React + routes serveur, D1 relationnel, R2 images, authentification de plateforme et rôle admin. Moteur de calcul pur partagé, recalcul depuis les sources à chaque lecture.
**Tech Stack:** TypeScript, Vinext/Next API, React, Tailwind, Drizzle, Cloudflare.
**Spec:** docs/superpowers/specs/2026-09-16-copro-design.md
